Air Quality Tools

Overview · Version 1.0 · November 2026

What it is

Three web calculators that apply EPA's air quality rules the same way every time and show their work: a NowCast calculator, an AQI calculator, and a unit converter for monitoring work. They run in any web browser at w00dsadam.github.io/Air_Quality_Tools, with nothing to install.

Why it exists

  • Faster checks. Staff get an AQI, NowCast or unit conversion in seconds instead of working through spreadsheets.
  • Consistent results. Every user gets the same answer from the same EPA breakpoints and rounding rules.
  • Transparent. The NowCast shows each step of the math, so results can be checked and explained.

Limits

  • CO and NO2 are not included; they can be added if needed.
  • The AQI calculator converts averages you enter; it does not average 24 hours of PM or SO2.
  • Results reflect the data entered. Real-time data is preliminary, so results can differ from AirNow for the same hour.
  • The tools support analysis and checking. Official values come from AQS and AirNow.
